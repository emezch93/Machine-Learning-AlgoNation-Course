What is Logistic Regression?

Despite its name, Logistic Regression is not a regression algorithm but a classificationA type of Supervised Learning where the goal is to predict discrete class labels for given input data algorithm. It's used to predict the probability that an instance belongs to a particular class, typically binary (0 or 1). The algorithm uses the sigmoid functionAlso called the logistic function, it maps any real-valued number to a value between 0 and 1, making it ideal for probability estimation to transform linear predictions into probabilities.

Unlike Linear Regression which predicts continuous values, Logistic Regression predicts probabilities that are then thresholded to produce class labels. It's particularly useful when you need to understand not just which class an instance belongs to, but also how confident the model is in that prediction. The output of logistic regression is always between 0 and 1, making it perfect for probability estimation.

The Sigmoid Function

The heart of logistic regression is the sigmoid function, which transforms any real number into a value between 0 and 1:

σ(z) = 1 / (1 + e^(-z))

Where z is the linear combination of features: z = w₀ + w₁x₁ + w₂x₂ + ... + wₙxₙ

0.0 (Certain Class 0) → 0.5 (Uncertain) → 1.0 (Certain Class 1)

Mathematical Foundation

Logistic Regression is based on the concept of maximum likelihood estimationA method of estimating the parameters of a statistical model by finding the parameter values that maximize the likelihood of making the observations given the parameters. Instead of minimizing the sum of squared errors (like in linear regression), we maximize the likelihood of observing our training data given our model parameters.

Step 1: The Logistic Function

We use the sigmoid (logistic) function to map any real number to a value between 0 and 1:

σ(z) = 1 / (1 + e^(-z))

Where z is the linear combination of our features and weights:

z = w₀ + w₁x₁ + w₂x₂ + ... + wₙxₙ = w^T x

The sigmoid function has several important properties:

  • σ(0) = 0.5
  • As z → ∞, σ(z) → 1
  • As z → -∞, σ(z) → 0
  • It's differentiable everywhere, which is crucial for optimization

Step 2: Probability Interpretation

We interpret the output of the sigmoid function as a probability:

P(y=1|x;w) = σ(w^T x) = 1 / (1 + e^(-w^T x))
P(y=0|x;w) = 1 - P(y=1|x;w) = 1 / (1 + e^(w^T x))

We can combine these into a single expression using the fact that y ∈ {0,1}:

P(y|x;w) = [P(y=1|x;w)]^y × [P(y=0|x;w)]^(1-y)

Step 3: The Log-Likelihood Function

To find the optimal weights, we maximize the likelihood of our training

L(w) = Π P(y⁽ⁱ⁾|x⁽ⁱ⁾;w) = Π [σ(w^T x⁽ⁱ⁾)]^y⁽ⁱ⁾ × [1-σ(w^T x⁽ⁱ⁾)]^(1-y⁽ⁱ⁾)

Working with products is difficult, so we take the logarithm to convert to a sum:

ℓ(w) = log L(w) = Σ [y⁽ⁱ⁾ log(σ(w^T x⁽ⁱ⁾)) + (1-y⁽ⁱ⁾) log(1-σ(w^T x⁽ⁱ⁾))]

This is called the log-likelihood function. We want to find w that maximizes ℓ(w).

Step 4: Gradient Ascent

Since there's no closed-form solution (unlike linear regression), we use gradient-based optimization. The gradient of the log-likelihood with respect to wⱼ is:

∂ℓ(w)/∂wⱼ = Σ (y⁽ⁱ⁾ - σ(w^T x⁽ⁱ⁾)) xⱼ⁽ⁱ⁾

We update our weights using gradient ascent (since we're maximizing):

wⱼ := wⱼ + α Σ (y⁽ⁱ⁾ - σ(w^T x⁽ⁱ⁾)) xⱼ⁽ⁱ⁾

Where α is the learning rate. This update rule has an intuitive interpretation: we adjust the weights based on the prediction error (y - prediction) multiplied by the feature value.

Model Evaluation

Evaluating logistic regression models requires different metrics than linear regression since we're dealing with classification:

Log Loss (Cross-Entropy Loss) = -1/n Σ [y⁽ⁱ⁾ log(ŷ⁽ⁱ⁾) + (1-y⁽ⁱ⁾) log(1-ŷ⁽ⁱ⁾)]
Accuracy = (TP + TN) / (TP + TN + FP + FN)
Precision = TP / (TP + FP)
Recall = TP / (TP + FN)
F1 Score = 2 × (Precision × Recall) / (Precision + Recall)

Where TP = True Positives, TN = True Negatives, FP = False Positives, FN = False Negatives.

# 🎯 Logistic Regression - Complete Implementation (Run All at Once)

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import accuracy_score, classification_report, confusion_matrix, roc_auc_score, roc_curve

class LogisticRegression:
    def __init__(self, learning_rate=0.01, n_iterations=1000):
        self.learning_rate = learning_rate
        self.n_iterations = n_iterations
        self.weights = None
        self.bias = None
        self.cost_history = []
    
    def sigmoid(self, z):
        # Clip z to prevent overflow
        z = np.clip(z, -500, 500)
        return 1 / (1 + np.exp(-z))
    
    def fit(self, X, y):
        n_samples, n_features = X.shape
        # Initialize parameters
        self.weights = np.zeros(n_features)
        self.bias = 0
        
        # Gradient descent
        for i in range(self.n_iterations):
            # Linear model
            linear_model = np.dot(X, self.weights) + self.bias
            # Apply sigmoid
            y_pred = self.sigmoid(linear_model)
            
            # Compute cost (log loss)
            cost = - (1/n_samples) * np.sum(y * np.log(y_pred + 1e-15) + (1 - y) * np.log(1 - y_pred + 1e-15))
            self.cost_history.append(cost)
            
            # Compute gradients
            dw = (1/n_samples) * np.dot(X.T, (y_pred - y))
            db = (1/n_samples) * np.sum(y_pred - y)
            
            # Update parameters
            self.weights -= self.learning_rate * dw
            self.bias -= self.learning_rate * db
            
            if i % 200 == 0:
                print(f"Iteration {i}: Cost = {cost:.6f}")
    
    def predict_proba(self, X):
        linear_model = np.dot(X, self.weights) + self.bias
        return self.sigmoid(linear_model)
    
    def predict(self, X, threshold=0.5):
        probabilities = self.predict_proba(X)
        return (probabilities >= threshold).astype(int)
    
    def get_params(self):
        return self.weights, self.bias

Advanced Implementation With Regularization

To prevent overfitting, we can add regularization to our logistic regression model. Here's an implementation with L2 regularization: 

     
          
        
        import numpy as np
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score, log_loss

class LogisticRegressionL2:
    def __init__(self, lr=0.01, n_iter=1000, reg_lambda=0.1):
        """
        Logistic Regression with L2 Regularization
        Parameters:
        - lr: learning rate
        - n_iter: number of iterations for gradient descent
        - reg_lambda: regularization strength
        """
        self.lr = lr
        self.n_iter = n_iter
        self.reg_lambda = reg_lambda
        self.theta = None
    
    def sigmoid(self, z):
        return 1 / (1 + np.exp(-z))
    
    def fit(self, X, y):
        # Add bias term
        X = np.c_[np.ones((X.shape[0], 1)), X]
        n_samples, n_features = X.shape
        self.theta = np.zeros(n_features)
        
        for _ in range(self.n_iter):
            # Predictions
            linear_model = np.dot(X, self.theta)
            y_pred = self.sigmoid(linear_model)
            
            # Gradient with L2 regularization (exclude bias term from regularization)
            gradient = (1/n_samples) * np.dot(X.T, (y_pred - y)) + (self.reg_lambda/n_samples) * np.r_[0, self.theta[1:]]
            
            # Update parameters
            self.theta -= self.lr * gradient
    
    def predict_proba(self, X):
        X = np.c_[np.ones((X.shape[0], 1)), X]
        return self.sigmoid(np.dot(X, self.theta))
    
    def predict(self, X, threshold=0.5):
        return (self.predict_proba(X) >= threshold).astype(int)

# ---------------- Demo ---------------- #
# Generate synthetic dataset
X, y = make_classification(n_samples=1000, n_features=10, n_classes=2, random_state=42)

# Train-test split
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Train model
model = LogisticRegressionL2(lr=0.1, n_iter=5000, reg_lambda=1.0)
model.fit(X_train, y_train)

# Predictions
y_pred = model.predict(X_test)
y_proba = model.predict_proba(X_test)

# Evaluation
acc = accuracy_score(y_test, y_pred)
loss = log_loss(y_test, y_proba)

print("Accuracy:", acc)
print("Log Loss:", loss)
print("Learned Weights:", model.theta)

Real-World Applications

Logistic Regression is one of the most widely used classification algorithms in various fields. Its simplicity, interpretability, and effectiveness make it a go-to method for many binary classification tasks.

Healthcare and Medicine

  • Disease Diagnosis: Predict whether a patient has a disease based on symptoms and test results
  • Patient Risk Stratification: Identify high-risk patients who may need more intensive care
  • Treatment Response: Predict whether a patient will respond to a particular treatment
  • Readmission Prediction: Forecast if a patient is likely to be readmitted to the hospital

Business and Finance

  • Credit Scoring: Determine whether to approve a loan application based on applicant's financial history
  • Customer Churn: Predict which customers are likely to stop using a service
  • Fraud Detection: Identify potentially fraudulent transactions
  • Marketing Response: Predict whether a customer will respond to a marketing campaign

Technology and Social Media

  • Spam Detection: Classify emails as spam or not spam
  • Sentiment Analysis: Determine if a product review is positive or negative
  • Click-Through Rate Prediction: Predict whether a user will click on an ad
  • Content Moderation: Flag potentially inappropriate content for review

Limitations and Considerations

While logistic regression is powerful, it has several important limitations:

  • Linear Decision Boundary: It can only learn linear decision boundaries in the feature space
  • Feature Engineering: Performance heavily depends on proper feature engineering and selection
  • Correlated Features: Highly correlated features can make the model unstable and coefficients hard to interpret
  • Outliers: While more robust than linear regression, outliers can still affect performance
  • Class Imbalance: Performance can suffer when one class is much more frequent than the other

When to Use Logistic Regression

Logistic regression is appropriate when:

  1. You need to solve a binary classification problem
  2. You want a probabilistic output (not just a class label)
  3. Interpretability is important (you need to understand how features affect predictions)
  4. Your features have a roughly linear relationship with the log-odds of the target
  5. You have a moderate-sized dataset and want a relatively simple, fast algorithm
  6. You need to implement the algorithm from scratch or understand its inner workings

Pro Tips for Better Performance

  • Feature Scaling: Normalize or standardize your features, especially if they're on different scales
  • Regularization: Use L1 or L2 regularization to prevent overfitting and handle multicollinearity
  • Feature Engineering: Create polynomial features or interaction terms to capture non-linear relationships
  • Handle Class Imbalance: Use techniques like SMOTE, class weights, or appropriate evaluation metrics
  • Calibration: If probability estimates need to be well-calibrated, consider using Platt scaling or isotonic regression
